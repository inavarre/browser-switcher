BrowserSwitcher Help

Open links in your work browser during work hours and your personal browser the rest of the time, with rules and a quick prompt for exceptions.

How it works

BrowserSwitcher becomes your Mac's default browser, but it never shows web pages itself. Every link you click in another app (Mail, Slack, Notes…) goes to BrowserSwitcher first, which immediately forwards it to the right real browser.

For each link it checks three things, in this order, and the first one that applies wins:

1Are you holding the prompt key? → show the browser prompt.
2Does a rule match? → open in that rule's browser, or show the prompt.
3Otherwise, use the schedule → work browser during work hours, personal browser the rest of the time.

Links are opened unchanged: nothing is removed from or added to the address.

Getting started

  1. Open Settings (menu-bar icon → Settings…, or open BrowserSwitcher again from Applications).
  2. On the Schedule tab, choose your work and personal browsers, your work hours and work days.
  3. Click Make Default Browser… (menu-bar panel or General tab) and confirm in the macOS dialog. You only do this once.
  4. Click a link in another app to check it opens where you expect.

Schedule

Work browser
Where links open during work hours. Browsers with several profiles (Chrome, Brave, Edge) list each profile, such as Google Chrome — Work, so links open in that profile.
Personal browser
Where links open outside work hours, on days you haven't selected, and whenever the schedule is off. Pick a profile here too. Plain Google Chrome — last-used profile opens in whichever Chrome profile you used most recently, which may be your work one.
Use work browser during work hours
Turns the schedule on or off. When off, links always go to your personal browser (rules and the prompt still work).
Starts / Ends
The work-hours window. A link at exactly the start time counts as work; at exactly the end time it counts as personal. Overnight ranges work too, e.g. 22:00 to 06:00.
Days
The days work hours apply. Highlighted days are on. The day is the one you click the link on.
If the browser the schedule picks isn't installed, the link opens in your other chosen browser, and failing that, Safari. A link is never dropped.

Prompt

The prompt is a small window that lets you pick a browser for a single link. It appears when you hold the prompt key while clicking a link, or when a rule says Show prompt.

Show the browser prompt while a key is held
Turns the prompt key on or off. Holding the key beats every rule and the schedule.
Key
Fn (Globe), Option, Shift, Control or Command. If Fn doesn't work on your keyboard, choose Option. Note that some apps use Command-click or Option-click for their own actions.

Choosing what the prompt shows

Browsers in the prompt
One switch per entry on the Prompt tab. Turn off anything you never pick. Terminal and iTerm start out turned off because they aren't browsers.
Profiles
Chrome, Brave and Edge get one entry per profile when you have more than one, labelled with the profile's name and badged with its picture. Picking one opens the link in that profile's window.
What isn't listed
Only apps installed in Applications (and Safari) appear. Copies in the Trash, old updater copies and test browsers downloaded by developer tools such as Puppeteer or Playwright are skipped, everywhere in BrowserSwitcher.

Using the prompt

ToDo this
Open in a browserClick it, or press its number 1–9. Entries after the ninth wrap onto a second row and are click-only.
Open in the highlighted browserReturn. The highlight is the browser you last picked in the prompt.
CancelEsc, or click outside the prompt. The link isn't opened.

Rules

Rules handle exceptions to the schedule. For example, always open GitHub in your work browser, or always ask which browser to use for links clicked in Slack.

Creating a rule

  1. Open Settings → Rules and click Add Rule.
  2. Give it a name (optional, for your own reference).
  3. Fill in Clicked in, Link host, or both.
  4. Choose what Open in does: a specific browser or browser profile, or Show prompt.

Changes save immediately; there's no Save button.

Rule settings

Checkbox
Turns the rule on or off without deleting it. Turned-off rules are dimmed.
Clicked in
The app the link was clicked in. Use the app menu next to the field to pick from apps that are running, or type the app's bundle ID. Leave it empty for any app.
Link host
The website part of the link, such as github.com. Leave it empty for any site. Only the host is checked, not the rest of the address.
Open in
A browser, a specific profile of a browser (such as Google Chrome — Personal), or Show prompt to choose each time.
⋯ menu
Move Up, Move Down and Delete Rule.

How rules match

  • Rules are checked top to bottom and the first match wins, so put specific rules above general ones.
  • If you fill in both Clicked in and Link host, both must match.
  • A rule needs at least one of the two. An empty rule never matches.
  • If the matching rule's browser isn't installed, the link follows the schedule.
  • Holding the prompt key always overrides rules.

Link host patterns

PatternMatchesDoesn't match
github.comgithub.com, gist.github.comnotgithub.com

docs.google.comdocs.google.comdrive.google.com
*zoom*zoom.us, us02web.zoom.usmeet.google.com

* matches any run of characters and ? matches exactly one. Matching ignores upper and lower case.

With the first and last examples together, put “GitHub from Slack” above “Ask every time for Slack links”, or the Slack rule will match first.

About “Clicked in”: BrowserSwitcher treats the app you're using when the link opens as the one it was clicked in. That's right for normal clicks, but links opened by apps running in the background may not match app rules.

Finding an app's bundle ID

Easiest: open the app, then pick it from the app menu next to Clicked in. Or run this in Terminal:

osascript -e 'id of app "Slack"'

Troubleshooting

Links open in the wrong browser
Check the General tab says BrowserSwitcher is the default browser. Then check your work hours and days, and whether a rule higher in the list matches first.
Links open in the wrong Chrome profile
On the Schedule tab (or in the rule), choose the profile itself, such as Google Chrome — Work, not Google Chrome — last-used profile.
I can't see the menu-bar icon
It may be hidden behind the camera notch, or turned off in System Settings → Menu Bar. Opening BrowserSwitcher from Applications always opens Settings.
Holding Fn doesn't show the prompt
Some keyboards don't report Fn. Pick another key on the Prompt tab.
A Slack rule doesn't match
Check the bundle ID with the app menu next to Clicked in. Test with a real link in Slack, not Test Link.
I want to stop using BrowserSwitcher
Choose another default browser in System Settings → Desktop & Dock → Default web browser, then quit BrowserSwitcher.
